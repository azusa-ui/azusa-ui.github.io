📦 R package walkthrough

MJMSTable — Interactive Learning Notes

A hands-on guide to generating publication-ready, MJMS/university-style statistical tables in R with one function call per test — built on top of gtsummary.

🙏 Full credit to the package developer: created out of an industrial training project and shared for the community — github.com/wnarifin/MJMSTable

📥 Getting started

Install the package directly from GitHub, then load it alongside dplyr for data wrangling:

# install once
install.packages("devtools")  # if not already installed
devtools::install_github("wnarifin/MJMSTable")

# load for every session
library(MJMSTable)
library(dplyr)

The package ships with a built-in demo dataset, mjms_data (500 simulated patients, 16 variables — demographics, biomarkers, diagnosis, treatment group, and a pre/post symptom pair) so every example below can be run immediately after loading the package.
